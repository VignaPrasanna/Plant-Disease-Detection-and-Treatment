**PLANT DISEASE DETECTION AND TREATMENT**

This Project focuses on aiding farmers by detecting plant diseases from their early signs and also provide treatment/prevention methods for the same.
Two CNN models are trained and the one with the better scores in the evaluation metrics is chosen and a streamlit application is built where the user can upload a leaf image and that image will be sent to the CNN model to predict if it is infected or healthy along with a confidence score for the prediction and provide treatment methods for it.
